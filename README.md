# 🎨 Cheat-Clip Web (`cliping-fe`)

Ultra-fast, modular frontend workspace for Cheat-Clip built with **SvelteKit**, **Svelte 5 Runes**, and **Tailwind CSS**.

## Features
- **Svelte 5 Universal Runes:** Zero-overhead reactivity with `$state` & `$derived`.
- **Dark Mode OLED:** Pitch black theme with Cinema Play Red accents.
- **In-Browser CSS Preview:** 9:16 mobile mockup without server re-render.
- **Interactive SVG Retention Curve:** Visualizes YouTube heatmap with Top 3 peak tags.
- **Keyboard Shortcuts (Linear Style):** `Space` Play/Pause, `I` In-point, `O` Out-point, `J`/`L` Seek 5s.
- **Real-Time SSE Streaming:** Live progress bar during rendering.
- **BYOK Security:** HTTP-Only cookie credentials.

## Quick Start
```bash
bun install
bun run dev
```
